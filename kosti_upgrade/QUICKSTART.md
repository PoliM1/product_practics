# 🎲 Система Лобби для Kosti-App - Быстрый Старт

## ✨ Что было создано

Полная система многопользовательского лобби с:
- ✅ Открытые и закрытые лобби (с паролями)
- ✅ 2-5 игроков в лобби
- ✅ Настройка количества костей и очков победы
- ✅ Real-time обновления через WebSocket
- ✅ Автоматическое управление хостом
- ✅ Современный красивый UI

## 🎯 Основные функции

### Создание Лобби
1. Нажмите "Играть"
2. Выберите тип лобби (открытое/закрытое)
3. Выберите количество игроков (2-5)
4. Нажмите "Создать Лобби"
5. Если закрытое - получите пароль и поделитесь с друзьями

### Присоединение к Лобби
**Открытое:**
- Выберите из списка → "Присоединиться"

**Закрытое:**
- Получите пароль от хоста
- Введите пароль → "Войти в лобби"

### Настройка и Начало Игры
**Хост:**
1. Настройте количество костей (1-10)
2. Настройте очки победы (50-500)
3. Дождитесь 2+ игроков
4. Нажмите "Начать игру"

**Другие игроки:**
- Ждут начала от хоста
- Видят изменения настроек в реальном времени

## 🐛 Решение проблем

**WebSocket не подключается?**
```javascript
const socket = io({
    transports: ['websocket', 'polling']
});
```

**Игроки не видят обновления?**
```python
# Используйте room в emit
emit('event', data, room=lobby_id)
```

**Лобби пропадают после перезапуска?**
- Лобби хранятся в памяти
- Для постоянного хранения используйте БД
