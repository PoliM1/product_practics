# 🎲 Система Лобби для Игры в Кости

## Описание

Полнофункциональная система лобби для многопользовательской игры в кости с поддержкой открытых и закрытых лобби.

## Возможности

### 🏠 Система Лобби
- **Создание лобби**
  - Открытые лобби (доступны всем)
  - Закрытые лобби (с автоматически генерируемым паролем)
  - Выбор количества игроков (2-5)

- **Присоединение к лобби**
  - Просмотр списка открытых лобби
  - Ввод пароля для закрытых лобби
  - Автоматическое обновление списка игроков

### ⚙️ Настройки Игры
- Выбор количества костей (1-10)
- Выбор количества очков для победы (50-500)
- Только хост может изменять настройки
- Все игроки видят обновления в реальном времени

### 🎮 Функционал
- WebSocket для обновлений в реальном времени
- Автоматическое назначение нового хоста при выходе текущего
- Защита от переполнения лобби
- Валидация настроек и данных

## Использование

### Создание Лобби

1. Перейдите на страницу "Лобби"
2. Выберите тип лобби:
   - **Открытое**: доступно всем игрокам
   - **Закрытое**: требует пароль для входа
3. Выберите максимальное количество игроков (2-5)
4. Нажмите "Создать Лобби"
5. Если выбрано закрытое лобби, вы получите пароль для приглашения друзей

### Присоединение к Лобби

**Открытое лобби:**
1. Выберите лобби из списка существующих
2. Нажмите "Присоединиться"

**Закрытое лобби:**
1. Получите пароль от хоста
2. Перейдите по ссылке на лобби
3. Введите пароль
4. Нажмите "Войти в лобби"

### Настройка Игры

После создания или присоединения к лобби вы попадете на страницу настроек:

**Для хоста:**
- Измените количество костей (1-10)
- Измените количество очков для победы (50-500)
- Дождитесь минимум 2 игроков
- Нажмите "Начать игру"

**Для других игроков:**
- Просматривайте настройки в реальном времени
- Дождитесь начала игры от хоста

## Технические детали

### Backend
- **Flask**: веб-фреймворк
- **Flask-SocketIO**: WebSocket для real-time обновлений
- **Sessions**: управление пользовательскими сессиями

### Frontend
- **HTML5/CSS3**: современная верстка
- **JavaScript**: динамическое взаимодействие
- **Socket.IO**: клиентская часть WebSocket

### Безопасность
- Генерация безопасных паролей с использованием `secrets`
- Валидация всех пользовательских данных
- Проверка прав доступа (только хост может менять настройки)
- Защита от переполнения лобби

## API Endpoints

### HTTP Routes
- `GET /` - Главная страница
- `GET /lobby` - Страница лобби
- `POST /create_lobby` - Создание нового лобби
- `GET/POST /join_lobby/<lobby_id>` - Присоединение к лобби
- `GET /game_settings/<lobby_id>` - Страница настроек игры
- `POST /update_settings/<lobby_id>` - Обновление настроек (только хост)
- `POST /start_game/<lobby_id>` - Начало игры (только хост)
- `GET /game/<lobby_id>` - Страница игры
- `POST /leave_lobby/<lobby_id>` - Выход из лобби

### WebSocket Events
- `join` - Присоединение к комнате
- `leave` - Выход из комнаты
- `player_joined` - Уведомление о новом игроке
- `player_left` - Уведомление о выходе игрока
- `settings_updated` - Обновление настроек игры
- `game_started` - Начало игры
- `new_host` - Назначение нового хоста

## Известные проблемы

- Лобби хранятся только в памяти (при перезапуске сервера теряются)
- Нет ограничения на количество лобби от одного пользователя
- Отсутствует система восстановления при разрыве соединения
